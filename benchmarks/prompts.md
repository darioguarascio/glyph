# Standard Prompts for Token Benchmark

Each prompt asks an AI to generate a complete, runnable program.

## Hello World

> Write a complete program that prints "Hello, World!" to stdout.

## Fibonacci

> Write a complete program with a recursive fibonacci function and print fib(10).

## FizzBuzz

> Write FizzBuzz: for i from 1 to 100, print Fizz if divisible by 3, Buzz if by 5, FizzBuzz if by both, else the number.
